# 🚀 Java Geliştirici Kampı: Müfredat ve Soru Bankası

Bu depo, sıfırdan zirveye backend geliştirme (Java & Spring Boot) süreçlerini öğrenmek ve pekiştirmek isteyenler için hazırlanmış **6 Haftalık Kapsamlı Eğitim Müfredatı ve Soru Bankasını** içermektedir.

## 📌 İçerikte Neler Var?
* **Adım Adım Teorik Föyler:** Java Temelleri, OOP Prensipleri, Koleksiyonlar ve Veri Yapıları.
* **Veritabanı Mimarisi:** Temel SQL, JDBC ve ORM mantığı.
* **Kurumsal Mimari:** Spring Boot, RESTful API tasarımı ve Katmanlı Mimari (Controller, Service, Repository).
* **600 Soruluk Dev Soru Bankası:** Her ünite için özenle hazırlanmış, kod çıktıları ve detaylı çözümler barındıran testler.
* **Sektörel Pratik Senaryoları:** Terminal tabanlı ATM, Kütüphane Otomasyonu ve Öğrenci Bilgi Sistemi (OBS) API'si kurguları.
